# Phase 1D.2 asset inventory

**Date:** 2026-11-02  
**Acquisition:** not approved. Phase 1E is blocked. No dataset was downloaded for this inventory.

Transcript-only evaluation compares strings. Waveform evaluation decodes an audio file. The synthetic AIFF files and the LibriSpeech FLAC files are present. No experiment in this repository has decoded them into the B0, B1, or B2 results below.

| Asset | Available | Permitted use now | Limitations |
